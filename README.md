# 🏎️ Ferrari Landing Page

A modern, responsive Ferrari-inspired landing page built to practice advanced front-end development and animation techniques. The project focuses on delivering a premium user experience with smooth interactions, clean layouts, and high-performance code.

## ✨ Features

* Responsive design for desktop, tablet, and mobile
* Modern HTML5 semantic structure
* SCSS architecture with organized partials
* JavaScript-powered interactive components
* Smooth scrolling and UI animations
* Optimized images and assets
* Clean, maintainable, and reusable code
* Fast loading performance

## 🛠️ Technologies Used

* HTML5
* SCSS (Sass)
* JavaScript (ES6+)
* Vite

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/yourusername/ferrari-landing-page.git
```

Navigate into the project:

```bash
cd ferrari-landing-page
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
